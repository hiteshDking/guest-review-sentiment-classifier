# Guest Review Sentiment Classifier

## Description

An AI-powered web application that analyzes guest reviews from multiple platforms and classifies them as Positive, Neutral, or Negative. The system helps rural homestay owners understand customer feedback, identify recurring issues, and improve guest experiences.

## Tech Stack

* Frontend: Next.js 14, React.js, Tailwind CSS
* Backend: Node.js, Express.js
* Database: MongoDB
* AI/ML: Python, Scikit-learn, NLP
* Version Control: Git & GitHub
